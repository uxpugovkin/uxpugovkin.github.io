Outcomes

The business cut costs by replacing a third-party CRM with a modern in-house platform for 20k customer support managers serving 25,000,000 clients (2022)

Problem

The bank’s client base grew exponentially and hit 25,000,000 in 2022. A legacy third-party solution no longer fits the bank’s needs, so an in-house department is building an internal solution that costs less and helps customer support managers resolve tickets faster. The migration is partially done, and much work remains.

Hard work

  • Designed scalable modules that serve as the daily workspace for 20k+ internal users
  • Conducted 5 moderated usability tests (3–4 users each) to ensure UI quality before development

Smart work

  • Owned end-to-end design for migrating core CRM activities off Oracle Siebel into a new in-house ecosystem serving a 25M+ customer base
  • Built a hands-on validation practice using USM, CJM, and usability testing, so high-stakes features were de-risked before reaching engineering

Shipped impact

  • Designed UX and UI for mission-critical Compliance and Bank Underwriting workflows, directly enabling real-time fraud reduction
  • Improved average task speed by redesigning the search bar for customer-support managers (A/B tested)
